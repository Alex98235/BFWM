# Bar Configuration

## Bar.* Reference

| Key | Type | Default | Description |
| --- | --- | --- | --- |
| `enabled` | boolean | `true` | Show the per-monitor status bar |
| `height` | integer | `32` | Bar height in pixels |
| `corner_radius` | integer | `1` | Bar window corner rounding in pixels |
| `margin` | table | `{ top=0, right=0, bottom=0, left=0 }` | Outer margin around the bar |
| `padding` | table | `{ top=0, right=0, bottom=0, left=0 }` | Inner padding inside the bar |
| `border` | table | `{ width=1, color="#ef9f76" }` | Bar border. `width=0` disables it |
| `font.name` | string | `"Segoe UI"` | Font face |
| `font.size` | integer | `18` | Font size in points |
| `font.weight` | integer | `800` (`FW_BOLD`) | Font weight (`400`=normal, `700`=bold) |
| `colors.background` | string | `"#303446"` | Bar background color |
| `colors.text` | string | `"#c6d0f5"` | Default text color |
| `colors.active_workspace` | string | `"#ef9f76"` | Active workspace tab color |
| `colors.inactive_workspace` | string | `"#626880"` | Inactive workspace tab color |
| `colors.tab_border` | string | `"#232634"` | Tab border color |
| `indicators` | array | 7 built-in indicators | Array of indicator entries |

## Bar.indicators[]

Each entry is a Lua table:

```lua
{ type = "<indicator_type>", align = "<alignment>", ... }
```

:::tip
I highly recommend installing a [Nerd Font](https://www.nerdfonts.com) (like JetBrainsMono Nerd Font)
to get access to a variety of glyphs that can be used as icons for the bar indicators.
Remember to set `Bar.font.name` if you decide to change font.
:::

### Common options

| Key | Type | Default | Description |
| --- | --- | --- | --- |
| `type` | string | `"workspaces"` | Indicator type (see below) |
| `align` | string | `"left"` | `"left"`, `"center"`, or `"right"` |
| `max_width` | integer | `0` | Maximum width in pixels |
| `size` | integer | `0` (bar default) | Font size override (points) |
| `format` | string | varies | Format string (see [Format specifiers](#format-specifiers)) |
| `color` | string | bar default text | Text color override |

### Indicator types

#### `"workspaces"` Workspace tabs with click-to-switch

| Key | Type | Default | Description |
| --- | --- | --- | --- |
| `show_position_bar` | boolean | `false` | Show a 3px scrollbar-style position indicator |
| `format` | string | `"{id}"` | Supports `{id}`, `{label}` |

#### `"title"` Focused window title *(no type-specific options)*

#### `"clock"` date/time display

| Key | Type | Default | Description |
| --- | --- | --- | --- |
| `format` | string | `"%H:%M"` | `strftime`-style format |

#### `"volume"` Audio level

| Key | Type | Default | Description |
| --- | --- | --- | --- |
| `format` | string | `"{icon}"` | Supports `{icon}`, `{percent}`, `{level}` |
| `icons` | string[5] | — | Level icons mapped 0%–100% |
| `icon_muted` | string | — | Icon when muted |
| `color_muted` | string | — | Text color when muted |

#### `"network"` WiFi / ethernet status

| Key | Type | Default | Description |
| --- | --- | --- | --- |
| `icons` | string[5] | — | Signal strength icons |
| `icon_disconnected` | string | — | Icon when disconnected |
| `icon_ethernet` | string | — | Icon for ethernet |
| `format_ethernet` | string | `"{icon}"` | Supports `{icon}` |
| `format_wifi` | string | `"{icon}"` | Supports `{icon}`, `{ssid}` |
| `color_disconnected` | string | — | Text color when disconnected |

#### `"cpu"` CPU load

| Key | Type | Default | Description |
| --- | --- | --- | --- |
| `icons` | string[5] | — | Load icons mapped 0%–100% |
| `poll_rate` | integer | `500` | Data-fetch interval in milliseconds |

#### `"memory"` Memory usage

| Key | Type | Default | Description |
| --- | --- | --- | --- |
| `icons` | string[5] | — | Load icons mapped 0%–100% |
| `poll_rate` | integer | `500` | Data-fetch interval in milliseconds |

## Format Specifiers

| Specifier | Description | Types |
| --- | --- | --- |
| `{icon}` | The selected icon for the current level/state | All icon-based types |
| `{ssid}` | The WiFi network name | Network |
| `{load}` / `{load:.Nf}` | CPU, memory, or volume load (0–100) | CPU, Memory, Volume |
| `{percent}` / `{percent:.Nf}` | Same as `{load}` (0–100) | Volume |
| `{level}` / `{level:.Nf}` | Raw volume level (0.0–1.0) | Volume |
| `{total_gb}` / `{total_gb:.Nf}` | Total physical memory in GB | Memory |
| `{used_gb}` / `{used_gb:.Nf}` | Used physical memory in GB | Memory |
| `{avail_gb}` / `{avail_gb:.Nf}` | Available physical memory in GB | Memory |
| `{id}` | The workspace id | Workspaces |
| `{label}` | The workspace label | Workspaces |

:::note
Without a `.Nf` suffix, `{load}`, `{percent}`, and `{level}` round to
an integer and GB values show one decimal place. Example: `format = "{percent.2f}"`.
:::
## Example

```lua
Bar.enabled = true
Bar.height = 32
Bar.colors.background = "#303446"
Bar.colors.text = "#c6d0f5"
Bar.colors.active_workspace = "#ef9f76"
Bar.colors.tab_border = "#232634"
Bar.indicators = {
  { type = "workspaces", align = "left" },
  { type = "title",      align = "center", max_width = 200 },
  { type = "volume",     align = "right",  icons = { " ", "▁", "▂", "▄", "▆" } },
  { type = "clock",      align = "right",  format = "%H:%M" },
}
```
