# Default Configuration

BFWM ships with sensible defaults. It works out of the box
without a config file. Below is the complete default configuration
as a `config.lua` you can save and customize.

> Save this as %APPDATA%\BFWM\config.lua and edit to your needs.

```lua
------------------------------
-- BFWM.* (Window Manager)
------------------------------

BFWM.gap_between = 6
BFWM.gap_edge = 8
BFWM.border_color = "#ef9f76"
BFWM.inactive_border = "#51576d"
BFWM.border_width = 4
BFWM.border_radius = 8
BFWM.focus_follows_mouse = false
BFWM.mouse_follows_focus = false
BFWM.layout = "dwindle"
BFWM.window_rules = {}
BFWM.workspaces = {}
BFWM.disabled_monitors = {}

-- WIP / dead features — do not use:
-- BFWM.unlock_window_resize = "LALT"
-- BFWM.unlock_window_move = "LALT"

------------------------------
-- BFWM.keybinds
------------------------------

BFWM.keybinds = {

  -- Window management
  { "Alt Q", "KillActive", {} },
  { "Alt F", "Fullscreen", {} },
  { "Alt X", "Minimize", {} },
  { "Alt W", "ToggleFloat", {} },

  { "Alt C", "ToggleGaps", {} },
  { "Alt D", "CycleLayout", { direction = "next" } },
  { "Alt Shift D", "CycleLayout", { direction = "prev" } },

  -- System
  { "Alt Shift R", "ReloadConfig", {} },
}

------------------------------
-- Bar.* (Status Bar)
------------------------------

Bar.enabled = true
Bar.height = 32

  background = "#303446",

Bar.indicators = {

  { type = "network",    align = "right",
    icons = { "󰤯", "󰤟", "󰤢", "󰤥", "󰤨" },

    icon_muted = "󰝟",
    format = "{percent}% {icon}" },
  { type = "cpu",        align = "right",

  { type = "memory",     align = "right",
    format = "{used_gb}/{total_gb}GB" },
  { type = "clock",      align = "right",

------------------------------

------------------------------

Snackbar.enabled = true

Snackbar.font_size = 20

Snackbar.close_on_click = true

Snackbar.click_to_expand = true
Snackbar.max_queue = 5

Snackbar.colors = {
  error = "#e78284",
  warn = "#e5c890",
  info = "#8caaee",
  debug = "#737994",
  normal = "#ef9f76",
}
```

## Built-in Ignored Windows

The following window classes are hardcoded in `src/window/filter.cpp`
and are always ignored regardless of config:

`Progman`, `WorkerW`, `Shell_TrayWnd`, `Shell_SecondaryTrayWnd`,
`MultitaskingViewFrame`, `TaskManagerWindow`,
`ApplicationFrameWindow`, `EdgeUiInputTopWndClass`,
`BFWMMonitorHelper`
