# Installation

## Installer

Get the installer for the latest version on the [releases](https://github.com/Alex98235/BFWM/releases) page on Github.
The installer file is called `BFWM-Setup-<version>.exe`

## Building from Source

### Prerequisites

- **CMake** 3.20+
- **C11 compiler**: MSYS2 **UCRT64** clang (**do not use MSVC**, it's not tested or supported)
- **C++20 compiler**: MSYS2 **UCRT64** clang++
- **Ninja** build driver

> Lua 5.4.7 is vendored as a part of the project files.

Using the `ucrt64` preset (as in the project README):

```sh
git clone https://github.com/Alex98235/BFWM.git
cd BFWM
cmake --preset ucrt64
cmake --build --preset ucrt64
```

For contributor setup, build options, and optional tooling (bfwm-tidy, graphify,
profiling, clangd), see the
[developer toolchain docs](https://github.com/Alex98235/BFWM/blob/main/doc-devtools/README.md).

The output binary is `build/BFWM.exe`.

### Running

```sh
cmake --build build --target run   # via CMake
./build/BFWM.exe               # or directly from the build directory
```

BFWM loads its configuration from `config.lua`. See [Getting Started](/getting-started) for the search order. If no file is found, BFWM falls back to its built-in defaults.
