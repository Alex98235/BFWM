BFWM is a dynamic tiling window manager for Windows inspired by
GlazeWM and Hyprland, fully configured via Lua.

## Features

- **Three layouts** — `dwindle` (binary-tree tiling), `monocle` (full-screen stacking), and `master` (stacked master/stack columns)
- **Multi-monitor**: independent workspaces on each display
- **Lua configuration**: hot-reloadable config with full key validation
- **Built-in status bar**: workspaces, clock, volume, network, CPU, memory indicators
- **Notification toast**: themable overlay for events and errors callable from the CLI or lua
- **Window rules**: automatic float, ignore, or workspace assignment on window creation
- **Sleep/wake recovery**: BFWM remembers its state and restores your workspaces when the system wakes from sleep.
- **Monitor hotplugging**: existing workspaces are reconciled when a monitor is plugged in/out.
